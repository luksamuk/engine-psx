# yyjson - Embedded JSON Library

**Source:** https://github.com/ibireme/yyjson  
**Author:** Yao Yuan (ibireme@gmail.com)  
**License:** MIT License (see header in yyjson.h)

## Purpose

High performance JSON parser used by cookcollision for handling large Tiled export files (>30KB).

## Why Single-File?

yyjson provides amalgamated single-file versions specifically for easy embedding:
- yyjson.c (source)
- yyjson.h (header)

This matches the project's philosophy of minimal dependencies.
