# RapidXML

**Source:** http://rapidxml.sourceforge.net/  
**Author:** Marcin Kalicinski  
**Version:** 1.13  
**License:** Boost Software License (based on distribution source)

RapidXML is a fast, header-only XML parser for C++.

## Usage

Single header - just include `rapidxml.hpp` in your C++ code.
